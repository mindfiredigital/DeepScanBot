# mindfiredigital/homebrew-tap

Homebrew tap repository for DeepScanBot and other mindfiredigital tools.

## What is a Homebrew Tap?

A Homebrew tap is a custom repository of formulae (or casks) that can be installed with Homebrew. This tap contains the DeepScanBot cask.

## Installation

```bash
brew tap mindfiredigital/DeepScanBot homebrew-tap
brew install deepscanbot
```
